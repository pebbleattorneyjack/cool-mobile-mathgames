# 🚀 Getting Started with Mobile GoodGames — GN Math

## What you get

- `index.html` — the live landing page (also served via GitHub Pages)
- `LINKS.md` — the master list of curated game links
- `manifest.json` + `sw.js` — PWA install support
- This repo is **static**: zero build steps, zero dependencies

## Run it (30 seconds)

```bash
git clone https://github.com/pebbleattorneyjack/mobile-goodgames.git
cd mobile-goodgames
python3 -m http.server 8000   # or just double-click index.html
```

## Publish to GitHub Pages (free hosting)

1. Push this repo to GitHub.
2. In your repo: **Settings → Pages → Source: `main` branch, `/ (root)` → Save**.
3. Wait ~1 minute. Your site is live at:
   `https://pebbleattorneyjack.github.io/mobile-goodgames`

## Grade-Level Guide

| Grade | Focus skills | Start here |
|---|---|---|
| K–1 | Counting, addition within 10 | Math Playground → Pre-K/K |
| 2–3 | Subtraction, intro multiplication | Multiplication.com Games |
| 4–5 | Fractions, long division | Math Games → Grade 4–5 |
| 6–8 | Ratios, integers, pre-algebra | Hooda Math → Middle School |
| 9–12 | Algebra, geometry, beyond | Khan Academy Math |

## Tips for students 🎒

- Play 10 minutes a day — spaced practice beats cramming.
- Start one grade *below* your comfort zone to build speed, then move up.

## Tips for teachers 👩‍🏫

- Assign one game per skill per week; have students screenshot high scores.
- All linked portals are ad-free or education-safe; verify against your district filter once at the start of term.
