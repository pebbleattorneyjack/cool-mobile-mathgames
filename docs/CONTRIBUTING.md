# 🤝 Contributing to Mobile GoodGames — GN Math

Thanks for helping kids find great math games! We accept:

## ✅ Link submissions (most common)

A game qualifies if it is:
1. **Free** — no trial traps, no pay-to-progress
2. **Mobile-friendly** — tap controls, no Flash, no hover-only UI
3. **School-safe** — ad-free or education-safe ads, no chat with strangers
4. **Math-focused** — the core loop must practice a real math skill

**To submit:** edit `LINKS.md`, add a row with 🟢/🟡 rating, and open a PR titled
`Add link: <game name> — <skill>`.

## 🐛 Bug reports & broken links

Open an issue titled `Broken link: <game>` and tell us your device/browser.

## 💡 Feature ideas

Open an issue with the `enhancement` label — e.g. dark mode, new categories, translations.

## 🎨 Code changes

- Keep `index.html` dependency-free (no build step) unless you add it under `/src` with clear docs.
- Match the existing SEO meta tags when editing the head of `index.html`.
- One PR = one logical change.
